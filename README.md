
# 🤖 RAG PDF Chatbot (LangChain + Llama 3)

This project implements a Retrieval-Augmented Generation (RAG) system to query and analyze PDF documents using open-source LLMs.

## 🎯 Objective

To build an end-to-end system that retrieves relevant document context and generates accurate responses using a large language model.

## ⚙️ Architecture

- Document loading and chunking  
- Embedding generation  
- Vector database for semantic search  
- LLM response generation  
- Gradio interface for user interaction  

---

## 🧠 Approach

- Used open-source LLM (Llama 3)  
- Implemented retrieval pipeline with LangChain  
- Built interactive UI using Gradio  
- Integrated embeddings for semantic search  

---

## 🚀 Features

- Ask questions over PDF documents  
- Context-aware responses  
- Fully open-source stack  
- Interactive web interface  

---

## 🛠️ Tech Stack

- Python  
- LangChain  
- Hugging Face  
- Llama 3  
- Gradio  

---

## 💡 Key Insights

- Retrieval significantly improves response accuracy  
- Chunking strategy impacts performance  
- Open-source models require careful tuning and integration
